# 32-bit RISC-V Processor with Parallel Graphics Accelerator

## Overview

This project presents the design and FPGA implementation of a **32-bit RISC-V processor integrated with a parallel graphics accelerator** for hardware-based graphics processing and VGA display output.

The system combines a custom single-cycle RISC-V processor with a memory-mapped graphics accelerator, framebuffer, and VGA controller. The processor executes instructions stored in instruction memory and communicates with the graphics subsystem through memory-mapped control registers.

The complete design is targeted for the **Xilinx Artix-7 based Nexys A7 FPGA board**.

---

Key Features

- 32-bit RISC-V processor
- Single-cycle processor architecture
- RISC-V ALU and control unit
- Register file implementation
- Instruction ROM
- Data memory
- Memory-mapped GPU interface
- Parallel graphics accelerator
- Framebuffer-based graphics storage
- VGA display controller
- FPGA implementation using Xilinx Vivado
- Nexys A7 / Artix-7 target platform

Processor Architecture
The processor is implemented as a 32-bit RISC-V single-cycle processor.
Main CPU Components
Program Counter (PC)
Stores the address of the current instruction and controls instruction sequencing.
Instruction ROM
Stores the RISC-V instructions executed by the processor.
Control Unit
Decodes instructions and generates the required control signals.
ALU
Performs arithmetic and logical operations required by the processor.
Register File
Provides the RISC-V general-purpose registers used for instruction execution.
Data Memory
Provides memory for reading and writing processor data.
Graphics Accelerator
The graphics subsystem is designed to perform graphics-related operations using dedicated hardware instead of relying entirely on software execution by the processor.
The graphics accelerator contains:
GPU MMIO
The GPU uses a memory-mapped interface through which the RISC-V processor can configure and communicate with the graphics subsystem.
Parallel Graphics Accelerator
The parallel graphics accelerator performs graphics operations using dedicated hardware logic, allowing graphics processing to operate independently from the main instruction execution path where applicable.
Framebuffer
The framebuffer stores pixel information generated by the graphics subsystem.
The VGA controller reads the required pixel information from the framebuffer and generates the corresponding VGA output signals.
